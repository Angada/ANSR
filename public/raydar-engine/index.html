RayDar Engine

How a batch travels from the Hunger seed, out through the YouTube and Reddit APIs, and back as ranked, evidence-grounded content ideas — every step, the code, and what it means.

The spine. Every ✦ AI step runs through the gated runPipeline(id,…) layer — provider · model · prompt from the swappable Admin registry, key from the encrypted Vault (BYOK), one log row per call. Every 🌐 fetch pulls its key from getIntegrationKey(id) and its query params from an editable business rule. Raw text never reaches a model outside the gate.
Hunger→ Terms→ YouTubeReddit→ Dedupe→ Classify→ Gap→ Research→ Ideate→ Validate→ Rank

Nine stages, in pipeline order. Each shows what the code is (from server/whisperer.js) and what it means.

Stage 5

Gap Analysis — pure math, no model

deterministic
topicSignals(items, gapMapVal)
What the code is
velocity = log10(max(views/ageDays)+1)/5        // momentum, ~100k/day → 1
demand   = # question-like comments + titles     // /how|why|which|worth it|vs/
supply   = item count × freshness                // halved if top item > 365 days stale
gap      = clamp(demandN / supplyQ)              // hunger ÷ what's already answered
gapType  = stale | emerging | unanswered | thin
What it means

The money step. Gap = demand ÷ supply. A topic with 20 unanswered questions and only 2 stale videos scores a high gap (big opportunity); a saturated topic scores low. Deterministic and auditable — it falls back to the configured gap_map when live metrics are missing.
